# Changelog

All notable versions of **Image Downloader**.

## [1.6.1]
- The default folder name has been changed from `JPG-Downloader` to `Image-Downloader` (it updates automatically if the previous name was in use).

## [1.6.0]
- Multilingual interface based on the browser's language: Spanish, English, Portuguese, French, German, and Italian.

## [1.5.2]
- The "Quality" selector has been renamed to "Version," with the options "Maximum resolution" and "Page size."

## [1.5.1]
- Fix: Thumbnails are now displayed on sites with anti-hotlinking protection; if no preview is available, a notice is shown.

## [1.5.0]
- Support for PNG, GIF, WebP, and AVIF, with format-based filtering.
- Background downloading, including progress tracking, a cancel button, and a notification upon completion.
- New name: Image Downloader.

## [1.4.0]
- Author credits, a link to GitHub, and a donation button via Ko-fi.

## [1.3.0]
- Extension icon.

## [1.2.0]
- Detection of the highest-resolution version (marked as "HD") and a version selector.

## [1.1.0]
- Fixed "download interrupted" error (by including the page's Referer header).
- Customizable destination folder and download progress tracking.

## [1.0.0]
- Initial version: detection of JPG images and bulk downloading.
